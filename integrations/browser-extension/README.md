# JobVeyra Pulse (browser extension)

A small floating card on every page: applications sent, a 14-day bar chart, replies and interviews,
and what needs you (sign-ins, portal checks, questions, deadlines). It reads `/api/digest` from the
JobVeyra dashboard on your own computer, once a minute; it never reads the pages you visit and never
contacts any other host.

Install (Chrome, Edge, Brave): open `chrome://extensions`, turn on Developer mode, choose
"Load unpacked" and select this folder. Start `jobveyra dashboard`. Click the extension icon to show
or hide the card; × hides it on the current site.
