معظم وكلاء البحث عن عمل إمّا يتوقفون قبل زر «إرسال» ويتركون لك النقر، وإمّا ينقرون «إرسال» على كل شيء ويأملون
الأفضل. يترك JobVeyra القرار لك، لكل مساحة عمل على حدة:

| `policy.submission` | ما يحدث |
|---|---|
| `batch_approve` (الافتراضي) | تراجع صفحة واحدة تعرض دفعة من الطلبات وتوافق عليها مرة واحدة. كل موافقة موقّعة على المحتوى الدقيق لإعلان الوظيفة؛ فإذا تغيّر الإعلان، يعود إلى المراجعة. |
| `auto` | تُقدَّم كل وظيفة تجتاز عوامل التصفية وحدّ الدرجة والحد اليومي. |
| `fill_only` | تُملأ النماذج وتتوقف قبل «إرسال». أنت من يضغط الزر. |

في كل الأوضاع، لا يُحتسب الطلب مُرسَلًا إلا عند تسجيل تأكيد صاحب العمل. النموذج المملوء أو الزر المنقور أو
الدرجة العالية لا تُحتسب أبدًا تقدّمًا.

## بدء سريع

<div dir="ltr">

```bash
pip install "jobveyra[charts]"     # Python 3.10+; charts need Pillow

jobveyra init ~/my-search && cd ~/my-search
# edit jobveyra.yml (who you are, where you want to work, policy, sources)
# write your fact base in cv/master.md
jobveyra doctor
jobveyra discover && jobveyra evaluate
jobveyra status
```

</div>

ثم دع وكيلًا يعالج قائمة الانتظار:

| بيئة التشغيل | الإعداد |
|---|---|
| Claude Code | `/plugin marketplace add EllenSyuu/JobVeyra` ثم `/plugin install jobveyra@jobveyra`؛ الأوامر `/jobveyra:search` و`/jobveyra:review` و`/jobveyra:apply` و`/jobveyra:digest` |
| Codex, OpenCode, Cursor, Gemini CLI, Copilot | افتح مساحة العمل؛ فهي تقرأ [`AGENTS.md`](../../AGENTS.md) (ويشير `GEMINI.md` إلى الملف نفسه) |
| بدون وكيل | كل خطوة أمر عادي؛ راجع `jobveyra --help` |
| Docker | `docker build -t jobveyra .` ثم `docker run --rm -v "$PWD:/workspace" jobveyra discover` |

## ركّز في أي مكان

مكان البحث مسألة إعدادات لا برمجة. المناطق مرتّبة وموزونة، ويمكن السماح بالعمل عن بُعد أو اشتراطه أو استبعاده،
ولكل عائلة وظائف (*track*) كلماتها المفتاحية الخاصة في المسمّيات الوظيفية، ومهاراتها المُثبتة، ونسختها من السيرة
الذاتية.

<div dir="ltr">

```yaml
focus:
  regions:
    - {name: Lisbon, match: [lisbon, lisboa, portugal], weight: 1.0}
    - {name: Remote Europe, match: [remote - europe, emea], weight: 0.7}
  remote: allow
  tracks:
    - {key: ds, label: Data science, titles: [data scientist, machine learning],
       skills: [python, sql, statistics], cv: cv/data-science.md}
  seniority_min: junior
  seniority_max: senior
  salary_floor: 40000
  salary_currency: EUR
```

</div>

الملف الكامل مع الشروح هو [`examples/jobveyra.yml`](../../examples/jobveyra.yml).

## كيف يعمل

<div dir="ltr">

```
sources        Greenhouse, Lever, Ashby, Workable, SmartRecruiters,
     │         Recruitee, UN Careers, USAJOBS, Remotive, any page
     │         with schema.org JobPosting, LinkedIn alert emails
     ▼
discover       focus filters, dedup by requisition and content
     ▼
evaluate       legitimacy checks, eight scored dimensions with
     │         evidence, hard blockers, lane
     ▼
materials      fabrication guard, self-negative wording guard,
     │         ATS text check
     ▼
approve        batch review page and signed approval
     ▼
submit         an agent drives the browser; the CLI leases one
     │         job at a time and records only confirmed sends
     ▼
learn          outcomes, funnel, patterns, score calibration,
               skill demand, follow-ups, daily digest
```

</div>

تعيش كل وظيفة في قائمة انتظار دائمة واحدة، ولها حالة واحدة بالضبط مع سببها
(`discovered`، `excluded`، `eligible`، `ready_to_submit`، `in_progress`، `submitted`،
`needs_check`، `retry_wait`، `blocked_auth`، `blocked_human`، `blocked_technical`).
تُرفض الانتقالات غير المسموح بها، وتنتهي عقود الإيجار (leases) بأمان، وإذا حدث تعطّل بعد النقر على «إرسال» تصبح
الحالة `needs_check` بدلًا من تقديم طلب مكرر.

## ماذا يفعل

**الاكتشاف**
- أحد عشر محوّلًا للمصادر تستخدم نقاط وصول عامة لا تتطلب تسجيل دخول، مع إعادة المحاولة والتراجع التدريجي وحدّ
  للطلبات لكل مضيف وفحص ملف robots.txt. الاكتشاف لا يكلّف أي استدعاء لنموذج.
- عوامل تصفية للمنطقة والعمل عن بُعد والأقدمية (مسمّيات بالإنجليزية والفرنسية والإسبانية والبرتغالية والألمانية)
  ونوع التوظيف والمسمّى وصاحب العمل، ولكلٍّ منها سبب مسجّل عندما يرفض وظيفة.
- إزالة التكرار حسب صاحب العمل ورقم الطلب الوظيفي، ثم حسب محتوى الإعلان.

**التقييم**
- ثمانية أبعاد: المهارات، والمسار، والأقدمية، والموقع، واللغة، والتعويض، والحداثة، وصاحب العمل. يحمل كل بُعد أدلة
  موسومة بأساسها: مقتبسة من الإعلان، أو مقروءة من حقول منظَّمة، أو تقديرية. البُعد الذي لا تدعمه إلا تقديرات يُوضع
  له سقف.
- تُقسَّم المتطلبات إلى إلزامية ومفضّلة قبل مطابقة المهارات.
- العوائق الحاسمة تُنهي التقييم: لا رعاية للتأشيرة في سوق لا يحق لك العمل فيه، أو لغة مطلوبة لا تتحدثها بمستوى B2
  أو أعلى، أو تصريح أمني، أو نوع التوظيف، أو أصحاب عمل تتجنبهم، أو إعلان مغلق.
- مؤشرات المصداقية: إعلانات مغلقة، وإعادة نشر، وإعلانات قديمة، ومجمّعات مواهب دائمة، وغياب الراتب، ومسمّيات مبهمة.
- تحليل الرواتب بمختلف العملات والفترات، وتحويلها إلى قيمة سنوية ومقارنتها بالحد الأدنى الذي حددته.
- يمكن لنموذج اختياري (Anthropic أو OpenAI أو Ollama أو أي نقطة وصول متوافقة مع OpenAI) أن يضيف مطابقة دلالية
  للمهارات، محدودة وموسومة على أنها تقدير. يُخفى اسمك وبريدك الإلكتروني وهاتفك وروابطك قبل أي استدعاء.

**المستندات**
- حارس ضد الاختلاق: كل رقم وتاريخ وصاحب عمل وشهادة جامعية وشهادة مهنية في المستند يجب أن يكون موجودًا في قاعدة
  الحقائق الخاصة بك.
- حارس ضد العبارات التي تقلّل من شأنك، بالإنجليزية والفرنسية والإسبانية والبرتغالية.
- فحص النص لأنظمة ATS: تغطية الكلمات المفتاحية، وبيانات الاتصال، وتشويش الاستخراج.
- زوايا خطاب التقديم مستمدة من الإعلان ومن مهاراتك المُثبتة فقط.

**بعد التقديم**
- سجل النتائج، وقمع يتضمن الوقت حتى أول رد، وأنماط الاستجابة حسب المصدر والبوابة والمسار والقناة مع فترات الثقة،
  ومعايرة الدرجة (Brier score وAUC) التي تنبّهك عندما يكون حدّك غير مناسب.
- الطلب على المهارات عبر الإعلانات التي اطّلعت عليها، والفجوات مقارنةً بملفك.
- متابعات مستحقة مع مسودة رسالة؛ والمواعيد النهائية كملفات تقويم.
- أوراق تحضير للمقابلات، وبنك قصص STAR+R يجب أن تستند كل مقاييسه إلى مصدر، ونصوص للتفاوض على العروض.

**التقارير**
- ملخص يومي بالبريد الإلكتروني مع رسم بياني متحرك يعمل أيضًا في برامج البريد التي لا تعرض إلا الإطار الأول، وسمتان
  فاتحة وداكنة، وجزء بنص عادي.
- إشعارات عبر Telegram أو Slack أو Discord أو Teams من خلال إعداد webhook واحد.
- كتلة حالة لأي ملف Markdown، مثل ملف README لمستودع خاص.

وصياغة رسائل التواصل، وملفات README بـ 18 لغة؛ ويؤتمت LinkedIn applier منصّتَي LinkedIn وIndeed مباشرةً ولديه لوحة
تحكم ويب محلية؛ ويدعم JobAppAgent حالة مشتركة بين عدة أجهزة عبر خلفية سحابية اختيارية.

## الخصوصية

تبقى بياناتك في مساحة عملك، ولا تدخل هذا المستودع أبدًا. يكتب الأمر `jobveyra init` ملف `.gitignore` يستبعد مساحة
العمل بأكملها. لا قياس عن بُعد، ولا خوادم خلفية. استدعاءات النماذج معطّلة افتراضيًا، وعند تفعيلها تُخفى بياناتك.
لا يُدخل المحرّك كلمات المرور أبدًا، ولا يحلّ اختبارات CAPTCHA، ولا ينشئ حسابات، ولا يقبل إقرارات قانونية، ولا يرسل أي
بريد إلكتروني غير ملخصك الخاص.
