  доказательства, готовит честные отклики, отправляет только то, что вы одобрили, и каждое утро сообщает, что

Большинство агентов для поиска работы либо останавливаются перед кнопкой «Отправить» и оставляют клик вам, либо
нажимают «Отправить» везде подряд в надежде на удачу. JobVeyra оставляет выбор за вами — отдельно для каждого
рабочего пространства:

| `policy.submission` | Что происходит |
|---|---|
| `batch_approve` (по умолчанию) | Вы просматриваете одну страницу со списком пакета откликов и одобряете его один раз. Каждое одобрение подписывается по точному содержимому вакансии; если вакансия изменится, она вернётся на проверку. |
| `auto` | Отправляется каждая вакансия, прошедшая ваши фильтры, порог оценки и дневной лимит. |
| `fill_only` | Формы заполняются и останавливаются перед «Отправить». Кнопку нажимаете вы. |

В любом режиме отклик считается отправленным только после того, как записано подтверждение от работодателя.
Заполненная форма, нажатая кнопка или высокая оценка никогда не считаются прогрессом.

<a id="quick-start"></a>

## Быстрый старт

```bash
pip install "jobveyra[charts]"     # Python 3.10+; charts need Pillow

jobveyra init ~/my-search && cd ~/my-search
# edit jobveyra.yml (who you are, where you want to work, policy, sources)
# write your fact base in cv/master.md
jobveyra doctor
jobveyra discover && jobveyra evaluate
jobveyra status
```

Затем пусть агент разберёт очередь:

| Среда | Настройка |
|---|---|
| Claude Code | `/plugin marketplace add EllenSyuu/JobVeyra`, затем `/plugin install jobveyra@jobveyra`; команды `/jobveyra:search`, `/jobveyra:review`, `/jobveyra:apply`, `/jobveyra:digest` |
| Codex, OpenCode, Cursor, Gemini CLI, Copilot | Откройте рабочее пространство; они читают [`AGENTS.md`](../../AGENTS.md) (`GEMINI.md` указывает на тот же файл) |
| Без агента | Каждый шаг — обычная команда; см. `jobveyra --help` |
| Docker | `docker build -t jobveyra .`, затем `docker run --rm -v "$PWD:/workspace" jobveyra discover` |

## Ищите где угодно

Где искать — это вопрос конфигурации, а не кода. Регионы упорядочены и имеют веса, удалённую работу можно
разрешить, сделать обязательной или исключить, а у каждого направления (*track*) свои ключевые слова в названиях
должностей, подтверждённые навыки и вариант резюме.

```yaml
focus:
  regions:
    - {name: Lisbon, match: [lisbon, lisboa, portugal], weight: 1.0}
    - {name: Remote Europe, match: [remote - europe, emea], weight: 0.7}
  remote: allow
  tracks:
    - {key: ds, label: Data science, titles: [data scientist, machine learning],
       skills: [python, sql, statistics], cv: cv/data-science.md}
  seniority_min: junior
  seniority_max: senior
  salary_floor: 40000
  salary_currency: EUR
```

Полный файл с комментариями — [`examples/jobveyra.yml`](../../examples/jobveyra.yml).

<a id="how-it-works"></a>

## Как это работает

```
sources        Greenhouse, Lever, Ashby, Workable, SmartRecruiters,
     │         Recruitee, UN Careers, USAJOBS, Remotive, any page
     │         with schema.org JobPosting, LinkedIn alert emails
     ▼
discover       focus filters, dedup by requisition and content
     ▼
evaluate       legitimacy checks, eight scored dimensions with
     │         evidence, hard blockers, lane
     ▼
materials      fabrication guard, self-negative wording guard,
     │         ATS text check
     ▼
approve        batch review page and signed approval
     ▼
submit         an agent drives the browser; the CLI leases one
     │         job at a time and records only confirmed sends
     ▼
learn          outcomes, funnel, patterns, score calibration,
               skill demand, follow-ups, daily digest
```

Каждая вакансия хранится в единой постоянной очереди и всегда имеет ровно одно состояние с указанием причины
(`discovered`, `excluded`, `eligible`, `ready_to_submit`, `in_progress`, `submitted`,
`needs_check`, `retry_wait`, `blocked_auth`, `blocked_human`, `blocked_technical`).
Недопустимые переходы отклоняются, аренды (leases) безопасно истекают, а сбой после нажатия «Отправить» приводит
к состоянию `needs_check`, а не к повторному отклику.

## Возможности

**Поиск вакансий**
- Одиннадцать адаптеров источников на публичных эндпоинтах без входа в аккаунт — с повторными попытками,
  экспоненциальной задержкой, ограничением частоты запросов для каждого хоста и проверкой robots.txt. Поиск не
  требует ни одного вызова модели.
- Фильтры по региону, удалённой работе, уровню (названия должностей на английском, французском, испанском,
  португальском и немецком), типу занятости, должности и работодателю; при каждом отказе записывается причина.
- Удаление дубликатов по работодателю и идентификатору вакансии, затем по её содержимому.

**Оценка**
- Восемь измерений: навыки, направление, уровень, местоположение, язык, вознаграждение, свежесть, работодатель.
  У каждого есть доказательства с пометкой об источнике: цитата из вакансии, данные из структурированных полей или
  оценка. Измерение, опирающееся только на оценки, ограничено сверху.
- Перед сопоставлением навыков требования делятся на обязательные и желательные.
- Жёсткие блокеры завершают оценку: нет визовой поддержки для рынка, где вы не можете работать; требуется язык,
  которым вы не владеете на уровне B2 или выше; допуск к секретным сведениям; тип занятости; работодатели, которых
  вы избегаете; закрытая вакансия.
- Признаки достоверности: закрытые вакансии, повторные публикации, устаревшие вакансии, постоянные кадровые
  резервы, отсутствие зарплаты, размытые названия должностей.
- Разбор зарплат в разных валютах и за разные периоды, пересчёт в годовую сумму и сравнение с вашим минимумом.
- Необязательная модель (Anthropic, OpenAI, Ollama или любой OpenAI-совместимый эндпоинт) может добавить
  семантическое сопоставление навыков — с ограниченным весом и пометкой «оценка». Перед любым вызовом ваше имя,
  email, телефон и ссылки маскируются.

**Материалы**
- Защита от выдумок: каждое число, дата, работодатель, учёная степень и сертификат в документе должны
  присутствовать в вашей базе фактов.
- Защита от самоуничижительных формулировок на английском, французском, испанском и португальском.
- Проверка текста для ATS: покрытие ключевых слов, контактные данные, шум при извлечении текста.
- Идеи для сопроводительного письма берутся из вакансии и только из ваших подтверждённых навыков.

**После отклика**
- Журнал результатов, воронка со временем до первого ответа, закономерности ответов по источникам, порталам,
  направлениям и каналам с доверительными интервалами, а также калибровка оценки (Brier score, AUC), которая
  подскажет, если ваш порог выбран неверно.
- Спрос на навыки по всем просмотренным вакансиям и пробелы относительно вашего профиля.
- Напоминания о повторных письмах с черновиком сообщения; дедлайны в виде файлов календаря.
- Листы подготовки к собеседованию, банк историй STAR+R, в котором каждая метрика должна ссылаться на источник,
  и сценарии переговоров об оффере.

**Отчёты**
- Ежедневная сводка по email с анимированным графиком, который работает и в клиентах, показывающих только первый
  кадр, со светлой и тёмной темами и текстовой версией.
- Уведомления в Telegram, Slack, Discord или Teams через одну настройку webhook.
- Блок статуса для любого Markdown-файла, например README приватного репозитория.

## Конфиденциальность

Ваши данные хранятся в вашем рабочем пространстве и никогда не попадают в этот репозиторий. `jobveyra init`
создаёт `.gitignore`, который исключает всё рабочее пространство. Никакой телеметрии, никакого бэкенда. Вызовы
модели по умолчанию отключены, а при включении данные маскируются. Движок никогда не вводит пароли, не решает
CAPTCHA, не создаёт аккаунты, не принимает юридические заверения и не отправляет никаких писем, кроме вашей
собственной сводки.

Единственное исключение зависит от вас: если вы своими словами зафиксируете постоянное согласие (`jobveyra authorize --consent ...`), общее заявление о достоверности и обязательные условия на последней странице отмечаются за вас, но только когда все ответы в форме проверены; заявление, противоречащее вашим известным фактам, не отмечается никогда.
