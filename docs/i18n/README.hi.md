ज़्यादातर जॉब-सर्च एजेंट या तो Submit से पहले रुक जाते हैं और क्लिक करना आप पर छोड़ देते हैं, या हर नौकरी पर Submit
दबाकर उम्मीद करते हैं कि सब ठीक होगा। JobVeyra यह फ़ैसला आपके हाथ में देता है, हर वर्कस्पेस के लिए अलग से:

| `policy.submission` | क्या होता है |
|---|---|
| `batch_approve` (डिफ़ॉल्ट) | आप एक पेज पर आवेदनों के एक बैच की समीक्षा करते हैं और उसे एक बार में मंज़ूरी देते हैं। हर मंज़ूरी नौकरी के विज्ञापन की हूबहू सामग्री पर साइन की जाती है; अगर विज्ञापन बदलता है, तो वह दोबारा समीक्षा के लिए लौट आता है। |
| `auto` | हर वह नौकरी जमा कर दी जाती है जो आपके फ़िल्टर, स्कोर की सीमा और रोज़ की अधिकतम संख्या को पार करती है। |
| `fill_only` | फ़ॉर्म भरे जाते हैं और Submit से पहले रुक जाते हैं। बटन आप दबाते हैं। |

हर मोड में, कोई आवेदन तभी भेजा हुआ माना जाता है जब नियोक्ता की पुष्टि दर्ज हो जाए। भरा हुआ फ़ॉर्म, दबाया हुआ बटन
या ऊँचा स्कोर कभी प्रगति नहीं गिना जाता।

<a id="quick-start"></a>

## जल्दी शुरुआत

```bash
git clone https://github.com/EllenSyuu/JobVeyra.git && cd JobVeyra
pip install ".[charts]"            # Python 3.10+; charts need Pillow

jobveyra init ~/my-search && cd ~/my-search
# edit jobveyra.yml (who you are, where you want to work, policy, sources)
# write your fact base in cv/master.md
jobveyra doctor
jobveyra discover && jobveyra evaluate
jobveyra status
```

इसके बाद किसी एजेंट को कतार पर काम करने दें:

| रनटाइम | सेटअप |
|---|---|
| Claude Code | `/plugin marketplace add EllenSyuu/JobVeyra`, फिर `/plugin install jobveyra@jobveyra`; कमांड `/jobveyra:search`, `/jobveyra:review`, `/jobveyra:apply`, `/jobveyra:digest` |
| Codex, OpenCode, Cursor, Gemini CLI, Copilot | वर्कस्पेस खोलें; ये [`AGENTS.md`](../../AGENTS.md) पढ़ते हैं (`GEMINI.md` भी उसी फ़ाइल की ओर इशारा करती है) |
| बिना एजेंट | हर चरण एक सामान्य कमांड है; `jobveyra --help` देखें |
| Docker | `docker build -t jobveyra .`, फिर `docker run --rm -v "$PWD:/workspace" jobveyra discover` |

## कहीं भी फ़ोकस करें

आप कहाँ खोजते हैं, यह कॉन्फ़िगरेशन का मामला है, कोड का नहीं। क्षेत्र क्रम से रखे जाते हैं और उन्हें वज़न दिया जाता है,
रिमोट काम को अनुमति दी जा सकती है, ज़रूरी बनाया जा सकता है या बाहर रखा जा सकता है, और हर भूमिका-समूह (एक *track*)
के अपने टाइटल कीवर्ड, प्रमाणित कौशल और CV का अपना संस्करण होता है।

```yaml
focus:
  regions:
    - {name: Lisbon, match: [lisbon, lisboa, portugal], weight: 1.0}
    - {name: Remote Europe, match: [remote - europe, emea], weight: 0.7}
  remote: allow
  tracks:
    - {key: ds, label: Data science, titles: [data scientist, machine learning],
       skills: [python, sql, statistics], cv: cv/data-science.md}
  seniority_min: junior
  seniority_max: senior
  salary_floor: 40000
  salary_currency: EUR
```

टिप्पणियों सहित पूरी फ़ाइल [`examples/jobveyra.yml`](../../examples/jobveyra.yml) में है।

<a id="how-it-works"></a>

## यह कैसे काम करता है

```
sources        Greenhouse, Lever, Ashby, Workable, SmartRecruiters,
     │         Recruitee, UN Careers, USAJOBS, Remotive, any page
     │         with schema.org JobPosting, LinkedIn alert emails
     ▼
discover       focus filters, dedup by requisition and content
     ▼
evaluate       legitimacy checks, eight scored dimensions with
     │         evidence, hard blockers, lane
     ▼
materials      fabrication guard, self-negative wording guard,
     │         ATS text check
     ▼
approve        batch review page and signed approval
     ▼
submit         an agent drives the browser; the CLI leases one
     │         job at a time and records only confirmed sends
     ▼
learn          outcomes, funnel, patterns, score calibration,
               skill demand, follow-ups, daily digest
```

हर नौकरी एक ही स्थायी कतार में रहती है, जिसमें उसकी ठीक एक स्थिति और उसका कारण दर्ज होता है
(`discovered`, `excluded`, `eligible`, `ready_to_submit`, `in_progress`, `submitted`,
`needs_check`, `retry_wait`, `blocked_auth`, `blocked_human`, `blocked_technical`)।
अमान्य बदलाव अस्वीकार किए जाते हैं, लीज़ सुरक्षित रूप से समाप्त होती हैं, और Submit क्लिक के बाद क्रैश होने पर
डुप्लिकेट आवेदन की जगह स्थिति `needs_check` बन जाती है।

## यह क्या करता है

**खोज**
- ग्यारह सोर्स एडैप्टर, जो बिना लॉगिन वाले सार्वजनिक एंडपॉइंट इस्तेमाल करते हैं, जिनमें री-ट्राई, बैकऑफ़, हर होस्ट के
  लिए रेट लिमिट और robots.txt जाँच शामिल हैं। खोज में किसी मॉडल कॉल का खर्च नहीं होता।
- क्षेत्र, रिमोट, वरिष्ठता (अंग्रेज़ी, फ़्रेंच, स्पैनिश, पुर्तगाली, जर्मन टाइटल), रोज़गार का प्रकार, टाइटल और नियोक्ता
  के फ़िल्टर; हर अस्वीकृति का कारण दर्ज किया जाता है।
- पहले नियोक्ता और रिक्विज़िशन आईडी से डुप्लिकेट हटाए जाते हैं, फिर विज्ञापन की सामग्री से।

**मूल्यांकन**
- आठ आयाम: कौशल, ट्रैक, वरिष्ठता, स्थान, भाषा, वेतन, ताज़गी, नियोक्ता। हर आयाम के साथ सबूत होते हैं, जिन पर उनका
  आधार लिखा होता है: विज्ञापन से उद्धृत, संरचित फ़ील्ड से पढ़ा गया, या अनुमानित। जो आयाम सिर्फ़ अनुमानों पर टिका हो,
  उसकी एक ऊपरी सीमा तय होती है।
- कौशल मिलाने से पहले आवश्यकताओं को अनिवार्य और वांछनीय में बाँटा जाता है।
- कठोर अवरोध मूल्यांकन वहीं खत्म कर देते हैं: उस बाज़ार के लिए वीज़ा स्पॉन्सरशिप नहीं जहाँ आप काम नहीं कर सकते, ऐसी
  अनिवार्य भाषा जिसे आप B2 या उससे ऊपर के स्तर पर नहीं बोलते, सुरक्षा मंज़ूरी, रोज़गार का प्रकार, वे नियोक्ता जिनसे आप
  बचना चाहते हैं, बंद हो चुका विज्ञापन।
- विश्वसनीयता के संकेत: बंद विज्ञापन, दोबारा पोस्ट किए गए विज्ञापन, पुराने विज्ञापन, हमेशा खुले टैलेंट पूल, वेतन का
  उल्लेख न होना, अस्पष्ट टाइटल।
- अलग-अलग मुद्राओं और अवधियों में वेतन पढ़ा जाता है, सालाना किया जाता है और आपकी न्यूनतम सीमा से तुलना की जाती है।
- एक वैकल्पिक मॉडल (Anthropic, OpenAI, Ollama या कोई भी OpenAI-संगत एंडपॉइंट) अर्थ-आधारित कौशल मिलान जोड़ सकता है,
  जो सीमित रहता है और अनुमान के रूप में चिह्नित होता है। किसी भी कॉल से पहले आपका नाम, ईमेल, फ़ोन और लिंक छिपा दिए
  जाते हैं।

**आवेदन सामग्री**
- मनगढ़ंत जानकारी से सुरक्षा: दस्तावेज़ में हर संख्या, तारीख, नियोक्ता, डिग्री और प्रमाणपत्र आपके तथ्य-आधार (fact base)
  में मौजूद होना चाहिए।
- अंग्रेज़ी, फ़्रेंच, स्पैनिश और पुर्तगाली में खुद को कमतर दिखाने वाले शब्दों से सुरक्षा।
- ATS टेक्स्ट जाँच: कीवर्ड कवरेज, संपर्क विवरण, एक्सट्रैक्शन की गड़बड़ी।
- कवर लेटर के बिंदु विज्ञापन से और सिर्फ़ आपके प्रमाणित कौशलों से लिए जाते हैं।

**आवेदन के बाद**
- नतीजों का लेखा-जोखा, पहले जवाब तक के समय के साथ फ़नल, स्रोत, पोर्टल, ट्रैक और लेन के हिसाब से जवाबों के पैटर्न
  (कॉन्फ़िडेंस इंटरवल के साथ), और स्कोर कैलिब्रेशन (Brier score, AUC), जो बताता है कि कब आपकी सीमा गलत है।
- आपके देखे गए विज्ञापनों में कौशलों की माँग, और आपकी प्रोफ़ाइल से उनका अंतर।
- ड्राफ़्ट संदेश के साथ बकाया फ़ॉलो-अप; समय-सीमाएँ कैलेंडर फ़ाइलों के रूप में।
- इंटरव्यू की तैयारी की शीट, STAR+R कहानियों का संग्रह जिसके हर मेट्रिक का स्रोत बताना ज़रूरी है, और ऑफ़र पर मोलभाव
  की स्क्रिप्ट।

**रिपोर्ट**
- रोज़ का ईमेल डाइजेस्ट, जिसमें एनिमेटेड चार्ट होता है जो उन क्लाइंट में भी काम करता है जो सिर्फ़ पहला फ़्रेम दिखाते हैं,
  लाइट और डार्क थीम, और एक सादा-टेक्स्ट हिस्सा।
- एक ही webhook सेटिंग से Telegram, Slack, Discord या Teams पर सूचनाएँ।
- किसी भी Markdown फ़ाइल के लिए एक स्टेटस ब्लॉक, जैसे किसी निजी रिपॉज़िटरी का README।

## निजता

आपका डेटा आपके वर्कस्पेस में रहता है, इस रिपॉज़िटरी में कभी नहीं। `jobveyra init` एक `.gitignore` लिखता है जो पूरे
वर्कस्पेस को बाहर रखता है। कोई टेलीमेट्री नहीं, कोई बैकएंड नहीं। मॉडल कॉल डिफ़ॉल्ट रूप से बंद रहते हैं और चालू होने पर
जानकारी छिपाई जाती है। यह इंजन कभी पासवर्ड नहीं डालता, CAPTCHA हल नहीं करता, अकाउंट नहीं बनाता, कानूनी घोषणाएँ
स्वीकार नहीं करता, और आपके अपने डाइजेस्ट के अलावा कोई ईमेल नहीं भेजता।
